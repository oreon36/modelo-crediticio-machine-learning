# 🏦 Modelo Crediticio con Machine Learning

Proyecto de clasificación desarrollado en **Python y Scikit-learn** para modelar la aprobación de solicitudes de crédito a partir de variables disponibles en un conjunto de datos crediticio.

## 🎯 Objetivo

Construir un flujo reproducible de Machine Learning que prepare los datos, transforme las variables y entrene un modelo de clasificación para estimar la aprobación de créditos.

## 🧩 Metodología

El proyecto sigue un flujo de trabajo de Ciencia de Datos que incluye:

1. Carga y exploración de los datos.
2. Revisión y preprocesamiento de variables.
3. Transformación de características numéricas y categóricas.
4. Construcción de un **Pipeline** de Scikit-learn.
5. Entrenamiento de un modelo de **Regresión Logística**.
6. Evaluación del desempeño.
7. Aplicación de **validación cruzada** para analizar la estabilidad del modelo.

## 🛠️ Tecnologías

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 📁 Contenido del repositorio

- `modelo_crediticio_machine_learning.ipynb`: notebook principal con el desarrollo del proyecto.
- `loan_sanction_train.csv`: conjunto de datos utilizado para entrenamiento y análisis.
- `loan_sanction_test.csv`: conjunto de datos de prueba.

## 🚀 Ejecución

Puedes abrir el notebook con Jupyter Notebook, JupyterLab o Google Colab. Instala previamente las librerías utilizadas en el proyecto y ejecuta las celdas siguiendo el orden presentado en el notebook.
